GPF FORECAST AUTO - SETUP (19 SEP 2026)

Google Sheet: https://docs.google.com/spreadsheets/d/1Ly2FYU5oAU-K_axJk739fJR9j9ZXABrh6olFizZQuNk/edit#gid=1148393739
Source file: GPF_Forecast_Auto.gs.txt in this repository.

1) Open the SAME Apps Script project that serves the current /exec endpoint (healthCheck: 2026-09-19-hotfix-1).
2) Back up the existing Code.gs and verify the project's Code.gs contains LOCKED_SPREADSHEET_ID.
3) Click + > Script to create a new Apps Script file named GPF_Forecast_Auto.
4) Open the source file in GitHub, copy ALL of its contents and paste into the NEW file. Save.
5) In the function selector choose installGpfForecastAuto, then Run and authorize access to Google Sheets, UrlFetchApp and scheduled triggers.
6) Check the Execution log. A successful result has status=success; thaiReady/goldReady depend on market-source completeness.
7) Check the Forecast_Auto tab: NAV base date/value, Yahoo prices, quote timestamps, statuses, estimated NAV and the old gold model comparison.
8) The installer creates three daily time triggers: 08:00-08:59, 14:00-14:59 (intraday snapshot), and 19:00-19:59 (after Thai market close), Asia/Bangkok. Re-running installer replaces only its own triggers (not other jobs). Changes to this GitHub source do NOT update an already deployed Apps Script project; paste the updated .gs code and rerun installGpfForecastAuto to activate the 14:00 snapshot.
9) To refresh manually, run refreshGpfForecastAuto in Apps Script. Do not edit set/spdr historical source rows for this automation.

IMPORTANT: The estimation is an indicative model, not official GPF NAV or a prediction guarantee. It uses 10 equity weights from set!B1:K1. The spreadsheet's Forecast_Auto!E5 calculates a cumulative-return scenario from the last published NAV: it uses ^SET.BK for the unlisted remainder when a matching anchor is available, and otherwise substitutes the weighted-return basket of the 10 listed stocks. J5 explains the active method, and M4:O9 shows an alternative scenario with the remainder held flat; these are assumptions, NOT confidence bounds. The existing script G5 status describes direct index quote completeness, not the validity of the sheet's basket-proxy estimate. Gold uses GLD ETF and USDTHB proxies. Quotes and official NAV dates may differ; this estimate is NOT the price that a later plan switch will necessarily receive. If stocks, NAV base, or dates are stale, the sheet estimate stays blank.
